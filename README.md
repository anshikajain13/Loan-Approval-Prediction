# Loan Approval Prediction

## Internship Project - Alfido Tech

### Objective

Build a machine learning model to predict loan approval status using applicant information.

### Dataset Features

* Gender
* Married
* Dependents
* Education
* Self Employed
* Applicant Income
* Coapplicant Income
* Loan Amount
* Loan Amount Term
* Credit History
* Property Area

### Models Used

1. Logistic Regression
2. Decision Tree

### Logistic Regression Results

* Accuracy: 78.86%
* Precision: 75.96%
* Recall: 98.75%
* F1 Score: 85.87%
* ROC-AUC: 73.87%

### Decision Tree Results

* Accuracy: 69.11%
* Precision: 75.61%
* Recall: 77.50%
* F1 Score: 76.54%
* ROC-AUC: 65.49%

### Best Model

Logistic Regression
